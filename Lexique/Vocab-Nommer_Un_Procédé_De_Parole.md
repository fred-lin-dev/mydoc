# 🎙️ Nommer un procédé de parole — quatorze mots

> **Fiche de vocabulaire — faite pour être mémorisée**, contrairement à une `Ref-`.
> Deux cartes par mot, dont une dans le sens *définition → mot*. Le pourquoi est dans
> [[Concept-Mot_Précède_L_Usage]], le critère d'entrée dans [[MOC-Lexique]].

**Famille : comment une chose est dite**, et non ce qu'elle dit. C'est le vocabulaire
qui manque pour commenter une prise de parole au lieu de la subir — celui que
[[Source-Le_Pouvoir_Rhétorique]] emploie sans toujours le définir.

---

## Les quatorze

**litote** :: dire moins pour faire entendre plus. *Ex : « ce n'est pas mauvais » pour signaler l'excellence.*
<!--ID: 1791036058263-->


**euphémisme** :: remplacer un terme brutal par un terme atténué qui ménage. *Ex : « plan social » pour des licenciements.*
<!--ID: 1791036058266-->


**prétérition** :: annoncer qu'on ne dira pas une chose, et la dire par là même. *Ex : « je ne parlerai pas de ses retards ».*
<!--ID: 1791036058270-->


**antiphrase** :: dire le contraire de ce qu'on veut faire entendre — le ressort de l'ironie. *Ex : « bravo » après une maladresse.*
<!--ID: 1791036058273-->


**périphrase** :: dire en plusieurs mots ce qu'un seul mot dirait. *Ex : « le roi des animaux » pour le lion.*
<!--ID: 1791036058276-->


**ellipse** :: supprimer un mot que l'auditeur rétablit seul, sans perte. *Ex : « lui, jamais » — le verbe est elliptique.*
<!--ID: 1791036058280-->


**amphibologie** :: construction qui se comprend de deux façons sans qu'on puisse trancher. *Ex : « j'ai vu l'homme avec le télescope ».*
<!--ID: 1791036058285-->


**incise** :: proposition courte glissée dans une phrase, entre virgules ou tirets. *Ex : « il est venu — personne ne l'attendait — et il a parlé ».*
<!--ID: 1791036058290-->


**digression** :: écart momentané hors du sujet, dont on revient. *Ex : la digression a duré dix minutes.*
<!--ID: 1791036058296-->


**laconique** :: qui dit en très peu de mots, au point que la brièveté se remarque. *Ex : sa réponse fut laconique : « non ».*
<!--ID: 1791036058300-->


**prolixe** :: qui emploie beaucoup plus de mots que la chose n'en demande. *Ex : un rapport prolixe de quarante pages pour une décision.*
<!--ID: 1791036058304-->


**sentencieux** :: qui parle par formules graves, comme s'il énonçait des vérités générales. *Ex : un ton sentencieux qui transforme un avis en maxime.*
<!--ID: 1791036058309-->


**redondance** :: information déjà donnée et répétée sans rien ajouter. *Ex : « monter en haut » est une redondance.*
<!--ID: 1791036058315-->


**truchement** :: intermédiaire par lequel une chose se fait — s'emploie dans « par le truchement de ». *Ex : il a obtenu l'accord par le truchement d'un tiers.*
<!--ID: 1791036058320-->


**hyperbole** :: exagération assumée qui ne cherche pas à tromper. *Ex : « des milliers de fois » est une hyperbole, pas un chiffre.*
<!--ID: 1791050495079-->


**concession** :: accorder un point à l'adversaire avant de le retourner. *Ex : la concession désarme avant que l'objection ne tombe.*
<!--ID: 1791050495083-->


**captatio** :: ouverture qui se concilie l'auditoire avant d'entrer dans le sujet. *Ex : trois phrases de captatio, puis l'attaque.*
<!--ID: 1791050495088-->


**anacoluthe** :: rupture de construction qui laisse une phrase inachevée dans sa syntaxe. *Ex : « moi, ma mère, elle disait toujours… ».*
<!--ID: 1791050495091-->


**pléonasme** :: ajout d'un mot dont le sens est déjà dans un autre. *Ex : « monter en haut » est un pléonasme.*
<!--ID: 1791050495095-->


**polysémie** :: propriété d'un mot qui porte plusieurs sens distincts. *Ex : la polysémie de « liberté » rend le débat stérile.*
<!--ID: 1791050495099-->


**équivoque** :: formulation qui laisse exprès deux lectures possibles. *Ex : sa réponse était équivoque, et volontairement.*
<!--ID: 1791050495102-->

## Les trois paires qui font le travail

| | | Ce que l'écart dit |
|---|---|---|
| **litote** | **euphémisme** | la direction. La litote **atténue pour amplifier** — l'auditeur doit corriger vers le haut ; l'euphémisme **atténue pour adoucir**, et il voudrait qu'on en reste là |
| **ellipse** | **redondance** | les deux bords de la même question : ce que l'auditeur peut rétablir seul. Williams en a fait une règle — voir [[Concept-Supprimer_L_Inférable]] |
| **laconique** | **prolixe** | le même axe, et aucun des deux n'est une qualité en soi : la question est le rapport entre la longueur et l'enjeu |
| **litote** | **antiphrase** | l'écart au dit. La litote dit **moins** et l'auditeur corrige vers le haut ; l'antiphrase dit **le contraire** et il inverse. Confondre les deux fait passer une ironie pour une modestie |

> ⚠️ **`emphase` n'est pas dans cette fiche, à dessein.** Le mot courant veut dire
> *insistance appuyée* ; chez Williams il désigne la **position accentuée en fin de
> phrase**, ce qui est tout autre chose. Deux sens incompatibles sur un mot sont une
> carte qui échoue dans les deux directions. Le sens de Williams est dans
> [[Concept-Topique_Et_Emphase]] et y reste.
