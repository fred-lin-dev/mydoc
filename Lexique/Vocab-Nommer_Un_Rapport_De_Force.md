# ♟️ Nommer un rapport de force — quinze mots

> **Fiche de vocabulaire — faite pour être mémorisée.** Deux cartes par mot, dont une
> dans le sens *définition → mot*. Critère d'entrée dans [[MOC-Lexique]].

**Famille : la forme que prend une domination.** C'est le vocabulaire de la phase 4 de
[[Ref-Lecture_Ordre_de_Priorité]] — neuf livres sur le pouvoir, et presque aucun de ces
mots n'y est défini. [[Concept-Pouvoir_Conféré]] dit que le pouvoir est **prêté** ; ces
mots nomment les formes du prêt.

---

## Les quinze

**ascendant** :: influence dominante qu'on exerce sur quelqu'un sans avoir à l'imposer. *Ex : il a un ascendant sur le groupe qu'aucun titre ne lui donne.*
<!--ID: 1791036058144-->


**hégémonie** :: domination telle que les autres s'y règlent d'eux-mêmes, sans contrainte explicite. *Ex : une hégémonie n'a plus besoin de gagner, il suffit qu'on la suppose.*
<!--ID: 1791036058157-->


**prééminence** :: premier rang reconnu et non disputé. *Ex : sa prééminence sur le dossier n'est contestée par personne.*
<!--ID: 1791036058161-->


**déférence** :: respect marqué qu'on témoigne à un rang plus qu'à une personne. *Ex : on l'écoute par déférence, pas par conviction.*
<!--ID: 1791036058166-->


**allégeance** :: lien de fidélité qui engage celui qui le prête. *Ex : changer de camp demande de rompre une allégeance.*
<!--ID: 1791036058172-->


**inféodé** :: placé dans une dépendance qui ôte la liberté de décider. *Ex : un service entièrement inféodé à sa direction.*
<!--ID: 1791036058176-->


**tutelle** :: autorité exercée sur quelqu'un, présentée comme étant pour son compte. *Ex : placé sous tutelle, il garde le titre et perd l'arbitrage.*
<!--ID: 1791036058179-->


**coercition** :: contrainte obtenue par la menace ou la force. *Ex : obtenir par la coercition ce que l'argument n'obtient pas.*
<!--ID: 1791036058182-->


**cooptation** :: entrée dans un groupe par désignation de ceux qui y sont déjà. *Ex : un jury recruté par cooptation ne surprend jamais.*
<!--ID: 1791036058185-->


**connivence** :: entente tacite entre deux parties qui se savent d'accord. *Ex : un regard de connivence a suffi.*
<!--ID: 1791036058189-->


**collusion** :: entente secrète conclue au détriment d'un tiers. *Ex : la collusion entre les deux acheteurs faussait l'enchère.*
<!--ID: 1791036058192-->


**clientélisme** :: échange durable de faveurs contre un soutien. *Ex : un clientélisme qui distribue des postes et récolte des voix.*
<!--ID: 1791036058195-->


**entrisme** :: pénétration progressive d'une organisation pour en orienter les décisions de l'intérieur. *Ex : l'entrisme ne prend jamais le pouvoir, il prend les commissions.*
<!--ID: 1791036058198-->


**mainmise** :: prise de contrôle effective, quelle que soit la forme officielle. *Ex : la mainmise d'un actionnaire minoritaire sur les nominations.*
<!--ID: 1791036058202-->


**prébende** :: revenu ou avantage attaché à une position plutôt qu'à un travail effectif. *Ex : un conseil d'administration réduit à une prébende.*
<!--ID: 1791036058205-->


**sujétion** :: état de celui qui est soumis, et le lien qui l'y tient. *Ex : une sujétion économique n'a pas besoin de loi.*
<!--ID: 1791050495020-->


**émancipation** :: sortie d'une sujétion, par rupture du lien. *Ex : l'émancipation se prend, elle ne s'accorde pas.*
<!--ID: 1791050495024-->


**arbitrage** :: pouvoir de trancher entre deux parties qui s'y soumettent. *Ex : celui qui garde l'arbitrage garde le dernier mot.*
<!--ID: 1791050495027-->


**entregent** :: habileté à se mouvoir dans un réseau de personnes. *Ex : il doit sa position à son entregent, pas à son dossier.*
<!--ID: 1791050495030-->


**capter** :: détourner à son profit ce qui allait ailleurs. *Ex : capter la rente d'un dispositif qu'on n'a pas créé.*
<!--ID: 1791050495035-->


**verrouiller** :: rendre une position impossible à contester. *Ex : la nomination a verrouillé le poste pour dix ans.*
<!--ID: 1791050495038-->


**instrumentaliser** :: se servir de quelqu'un ou d'une cause comme d'un moyen. *Ex : instrumentaliser un conflit pour en tirer un mandat.*
<!--ID: 1791050495042-->

## Les quatre paires qui font le travail

| | | Ce que l'écart dit |
|---|---|---|
| **connivence** | **collusion** | la victime. La connivence est **une entente sans tort** ; la collusion suppose **un tiers lésé** — les confondre est une accusation, pas une description |
| **ascendant** | **coercition** | le coût. L'ascendant **n'a rien à dépenser** ; la coercition dépense à chaque usage, et [[Concept-Pouvoir_Conféré]] explique pourquoi elle s'épuise |
| **hégémonie** | **prééminence** | l'étendue. La prééminence est **un rang dans un ordre admis** ; l'hégémonie **est** l'ordre, et fixe ce qui compte comme rang |
| **tutelle** | **inféodé** | le prétexte. La tutelle se dit **pour le bien** du subordonné ; l'inféodation ne se justifie pas, elle se constate |

> **Le mot qui vaut la fiche entière : `hégémonie`.** Il nomme ce que la phase 4 décrit
> sans jamais le dire — une domination qui n'a plus besoin de s'exercer parce qu'on la
> suppose. C'est exactement [[Concept-Vaincre_Sans_Combattre]] vu du côté du fort, et
> [[Concept-Fabrication_Du_Consentement]] en est le moyen.
