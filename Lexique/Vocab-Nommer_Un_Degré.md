# 📏 Nommer un degré — quinze mots

> **Fiche de vocabulaire — faite pour être mémorisée.** Deux cartes par mot, dont une
> dans le sens *définition → mot*. Critère d'entrée dans [[MOC-Lexique]].

**Famille : dire combien, sans chiffrer.** C'est la famille la plus directement utile de
ce vault : les 98 champs `fiabilite_note` ne font rien d'autre que graduer une force de
preuve, et ils le font aujourd'hui avec « plutôt », « assez », « très ». Ces mots
remplacent exactement ces béquilles.

---

## Les quinze

**prépondérant** :: qui l'emporte sur tous les autres facteurs. *Ex : un seul facteur est prépondérant, les autres sont du bruit.*
<!--ID: 1791050494931-->


**substantiel** :: assez important pour changer la conclusion. *Ex : l'écart est substantiel, pas anecdotique.*
<!--ID: 1791050494935-->


**marginal** :: si faible qu'il ne change rien à la décision. *Ex : l'effet est réel et marginal : les deux à la fois.*
<!--ID: 1791050494940-->


**résiduel** :: ce qui reste après que l'essentiel a été expliqué. *Ex : il reste un écart résiduel que rien ne couvre.*
<!--ID: 1791050494943-->


**ténu** :: si mince qu'on peut douter de son existence. *Ex : le lien est ténu et l'auteur le présente comme établi.*
<!--ID: 1791050494947-->


**patent** :: visible au point que le nier serait de mauvaise foi. *Ex : la contradiction est patente dès le deuxième chapitre.*
<!--ID: 1791050494951-->


**latent** :: présent mais non encore manifesté. *Ex : un désaccord latent qu'aucune réunion n'a fait surgir.*
<!--ID: 1791050494955-->


**prégnant** :: qui s'impose à la perception avant tout examen. *Ex : l'exemple est prégnant, et c'est précisément le piège.*
<!--ID: 1791050494959-->


**notable** :: digne d'être relevé, sans préjuger de son poids. *Ex : une exception notable, dont on ne sait pas quoi conclure.*
<!--ID: 1791050494963-->


**négligeable** :: dont on peut ne pas tenir compte sans fausser le résultat. *Ex : négligeable sur l'ensemble, décisif sur ce cas.*
<!--ID: 1791050494968-->


**appréciable** :: assez grand pour être mesuré et pour compter. *Ex : un gain appréciable, de l'ordre du tiers.*
<!--ID: 1791050494973-->


**sensible** :: perceptible, en parlant d'une variation. *Ex : une baisse sensible depuis le changement de méthode.*
<!--ID: 1791050494977-->


**exhaustif** :: qui couvre tous les cas, sans exception laissée dehors. *Ex : la liste se veut exhaustive et oublie deux catégories.*
<!--ID: 1791050494981-->


**circonscrit** :: dont les limites sont posées et tenues. *Ex : un désaccord circonscrit à un seul point de méthode.*
<!--ID: 1791050494985-->


**afférent** :: qui se rapporte à, qui relève de. *Ex : les coûts afférents au dispositif, et eux seuls.*
<!--ID: 1791050494989-->

## Les quatre paires qui font le travail

| | | Ce que l'écart dit |
|---|---|---|
| **marginal** | **négligeable** | la décision. *Marginal* décrit **la taille** ; *négligeable* est un **jugement** : on a décidé de ne pas en tenir compte |
| **patent** | **prégnant** | où est l'évidence. Le patent l'est **dans les faits** ; le prégnant l'est **dans la perception** — et peut être faux, c'est tout l'intérêt du mot |
| **ténu** | **latent** | ce qui manque. Le ténu est **faible** ; le latent est **entier mais pas encore sorti** — les confondre fait rater un risque |
| **substantiel** | **appréciable** | ce qui est affirmé. *Substantiel* dit que ça **change la conclusion** ; *appréciable* dit seulement que c'est **mesurable** |

> **Pourquoi cette famille devrait passer avant les trois autres.** Ce vault gradue des
> preuves à longueur de journée : 70 `🟠 contesté`, 20 `🟢`, 5 `🔴`, 4 `🔵`. Chacune de
> ces notes dit *dans quelle mesure* un appui tient — et le dit avec des adverbes.
> C'est la seule famille dont chaque mot a déjà un emploi qui l'attend.
