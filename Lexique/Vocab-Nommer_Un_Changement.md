# 🔄 Nommer un changement — quinze mots

> **Fiche de vocabulaire — faite pour être mémorisée.** Deux cartes par mot, dont une
> dans le sens *définition → mot*. Critère d'entrée dans [[MOC-Lexique]].

**Famille : la forme d'une évolution**, pas sa direction. Dire qu'une chose « change »
n'informe de rien : ce qui informe, c'est si elle change **par paliers, par à-coups, sans
retour possible, ou en s'inversant**. C'est le vocabulaire de
[[Source-Thinking_in_Systems]], que le vault emploie sans l'avoir nommé.

---

## Les quinze

**inflexion** :: le **moment** où une tendance change de direction sans s'arrêter. *Ex : une inflexion nette à partir de 2019.*
<!--ID: 1791050494876-->


**infléchir** :: **faire** changer la direction d'une tendance en cours. *Ex : la mesure a infléchi la courbe, pas inversé.*
<!--ID: 1791050494881-->


**amorce** :: tout premier moment d'un processus, encore réversible. *Ex : c'est une amorce de reprise, pas une reprise.*
<!--ID: 1791050494884-->


**enclencher** :: déclencher un processus qui se poursuivra de lui-même. *Ex : la première embauche enclenche les suivantes.*
<!--ID: 1791050494888-->


**graduel** :: qui se fait par degrés perceptibles. *Ex : un durcissement graduel, jamais annoncé.*
<!--ID: 1791050494892-->


**incrémental** :: qui progresse par ajouts petits et **continus**, sans palier. *Ex : une amélioration incrémentale, invisible sur un mois.*
<!--ID: 1791050494895-->


**par paliers** :: qui progresse par sauts séparés de plateaux. *Ex : la compétence vient par paliers, pas en pente.*
<!--ID: 1791050494899-->


**inexorable** :: dont rien n'arrête le cours. *Ex : un déclin inexorable qu'on a mis dix ans à nommer.*
<!--ID: 1791050494902-->


**irréversible** :: qui ne peut plus être défait. *Ex : le pas est irréversible : on ne revient pas en arrière.*
<!--ID: 1791050494906-->


**s'éroder** :: perdre lentement de sa substance sous un effet continu. *Ex : la confiance s'érode sans incident visible.*
<!--ID: 1791050494909-->


**se cristalliser** :: prendre une forme fixe après une période instable. *Ex : l'opposition s'est cristallisée sur un seul point.*
<!--ID: 1791050494912-->


**décanter** :: laisser se séparer l'essentiel du reste, avec le temps. *Ex : laisser la question décanter une semaine.*
<!--ID: 1791050494915-->


**s'enliser** :: s'immobiliser progressivement dans ce dont on ne sort plus. *Ex : le projet s'enlise depuis le troisième comité.*
<!--ID: 1791050494919-->


**basculer** :: passer d'un état à l'autre d'un seul coup, après une accumulation. *Ex : l'équilibre a basculé en une réunion.*
<!--ID: 1791050494922-->


**entériner** :: faire passer dans les faits établis ce qui n'était qu'un état. *Ex : la décision entérine une pratique vieille de deux ans.*
<!--ID: 1791050494926-->

## Les quatre paires qui font le travail

| | | Ce que l'écart dit |
|---|---|---|
| **graduel** | **par paliers** | la forme de la pente. Le graduel est **continu** ; les paliers supposent des **plateaux** où rien ne bouge — et c'est ce qui décourage |
| **inexorable** | **irréversible** | ce qui est impossible. L'inexorable ne peut pas **s'arrêter** ; l'irréversible ne peut pas **se défaire**. Une chose peut être l'un sans l'autre |
| **s'éroder** | **basculer** | le régime. L'érosion est **lente et sans événement** ; le basculement est **soudain après accumulation** — et c'est souvent la même cause |
| **amorce** | **enclencher** | la suite. Une amorce peut **ne mener à rien** ; ce qui est enclenché **continue sans qu'on y revienne** |
| **incrémental** | **par paliers** | la continuité. L'incrémental **ne s'arrête jamais**, même imperceptiblement ; les paliers ont des **plateaux plats** |
| **inflexion** | **infléchir** | la catégorie : un **moment** contre une **action**. Ils se distinguent par la glose, pas par le sens — et c'est pour ça qu'elles ont été réécrites |

> **Le mot qui vaut la fiche : `basculer`.** Il nomme ce que
> [[Concept-Boucle_De_Rétroaction]] décrit en mécanique et
> [[Concept-Cygne_Noir]] en conséquences : une accumulation invisible, puis un seul
> coup. Sans ce mot on dit « ça a changé d'un coup », qui perd l'accumulation — c'est-à-dire
> la seule partie qu'on aurait pu voir venir.
