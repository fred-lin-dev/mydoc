# 🧩 Nommer un raisonnement — douze mots

> **Fiche de vocabulaire, pas une référence consultée.** Contrairement aux `Ref-`,
> celle-ci **est faite pour être mémorisée** : chaque ligne produit deux cartes, dont
> une dans le sens *définition → mot*, qui est le seul sens utile pour parler.
> Le pourquoi est dans [[Concept-Mot_Précède_L_Usage]].

**Critère d'entrée — et il est strict.** Un mot n'entre ici que s'il **remplace une
périphrase que tu emploies déjà**. Pas un mot rare, pas un mot joli : un mot qui
raccourcit quelque chose que tu dis en huit mots aujourd'hui. Un mot qu'on n'aurait pas
eu l'occasion d'employer n'est pas du vocabulaire, c'est de la décoration.

**Famille retenue : juger un raisonnement.** C'est l'usage le plus fréquent de ce
vault — le champ `fiabilite` ne fait rien d'autre que ça, soixante-dix fois.

## Les douze

**sophisme** :: raisonnement faux présenté comme valide, et présenté ainsi à dessein. *Ex : « tout le monde le fait » n'est pas un argument mais un sophisme.*
<!--ID: 1791034994261-->


**paralogisme** :: le même raisonnement faux, mais commis de bonne foi — la faute est logique, pas morale. *Ex : il ne te manipule pas, c'est un paralogisme.*
<!--ID: 1791034994266-->


**pétition de principe** :: tenir pour acquis, dans les prémisses, ce qu'il s'agissait précisément de démontrer. *Ex : « c'est efficace parce que ça marche » est une pétition de principe.*
<!--ID: 1791034994269-->


**spécieux** :: qui a l'apparence de la justesse et ne la supporte pas à l'examen. *Ex : l'argument est spécieux : il est bien construit et sa prémisse est fausse.*
<!--ID: 1791034994273-->


**aporie** :: difficulté où deux raisonnements également solides se contredisent, sans issue disponible. *Ex : les antinomies de Kant sont des apories, pas des erreurs.*
<!--ID: 1791034994277-->


**tautologie** :: énoncé vrai par sa seule forme, donc dépourvu d'information. *Ex : « les gens qui réussissent sont ceux qui n'échouent pas » est une tautologie.*
<!--ID: 1791034994280-->


**truisme** :: vérité si évidente que l'énoncer n'apprend rien — à distinguer de la tautologie, qui est vraie par construction. *Ex : « il faut travailler pour progresser » est un truisme.*
<!--ID: 1791034994283-->


**corollaire** :: conséquence qui découle d'une thèse déjà établie, sans démonstration nouvelle. *Ex : la loi de viabilité financière est un corollaire du capital de compétences.*
<!--ID: 1791034994286-->


**étayer** :: soutenir une affirmation par ce qui la rend crédible. *Ex : la thèse est plausible mais rien ne l'étaye.*
<!--ID: 1791034994290-->


**réifier** :: traiter comme une chose ce qui n'est qu'une abstraction ou une relation. *Ex : parler du pouvoir comme d'un objet qu'on détient, c'est le réifier.*
<!--ID: 1791034994293-->


**ad hoc** :: introduit pour la seule occasion, afin de sauver une thèse que l'objection menaçait. *Ex : l'exception est ad hoc — elle n'a aucune raison d'être hors de ce contre-exemple.*
<!--ID: 1791034994296-->


**téléologique** :: qui explique par la fin visée plutôt que par la cause. *Ex : dire que l'œil est fait pour voir est une explication téléologique.*
<!--ID: 1791034994299-->


**prémisse** :: proposition de départ d'un raisonnement, et dont sa conclusion dépend. *Ex : l'argument est valide, mais sa prémisse est fausse.*
<!--ID: 1791050495046-->


**postulat** :: prémisse qu'on assume **sans la démontrer**, et qui s'annonce comme telle. *Ex : c'est un postulat, pas une conclusion.*
<!--ID: 1791050495050-->


**inférence** :: passage d'une proposition à une autre qu'on en tire. *Ex : l'inférence est hâtive : rien n'autorise ce saut.*
<!--ID: 1791050495054-->


**subsumer** :: ranger un cas particulier sous une règle générale. *Ex : tu subsumes trois phénomènes distincts sous un seul mot.*
<!--ID: 1791050495058-->


**circulaire** :: dont la conclusion est déjà contenue dans ses prémisses. *Ex : le raisonnement est circulaire, il ne démontre rien.*
<!--ID: 1791050495061-->


**contingent** :: qui pourrait être autrement — opposé à nécessaire. *Ex : c'est contingent, donc ça ne prouve aucune loi.*
<!--ID: 1791050495065-->


**corrélat** :: ce qui varie avec autre chose, sans qu'un lien de cause soit établi. *Ex : un corrélat n'est pas une cause.*
<!--ID: 1791050495070-->


**réfutable** :: dont on peut concevoir ce qui le démentirait. *Ex : une thèse irréfutable n'est pas forte, elle est vide.*
<!--ID: 1791050495074-->

## Les trois paires qui font tout le travail

*C'est la partie de la fiche qui ne se mémorise pas en cartes isolées : les mots se
tiennent par deux, et c'est l'écart entre les deux qui est l'information.*

| | | Ce que l'écart dit |
|---|---|---|
| **sophisme** | **paralogisme** | l'intention. Le premier accuse, le second excuse — les confondre, c'est prêter une mauvaise foi qu'on n'a pas constatée |
| **tautologie** | **truisme** | l'un est vrai **par sa forme** et ne peut pas être faux ; l'autre est vrai **par le monde** et n'est seulement pas intéressant |
| **spécieux** | **ad hoc** | où est le défaut. Le spécieux trompe par sa **forme** ; l'*ad hoc* trompe par son **moment** — il arrive après l'objection, taillé pour elle |
| **prémisse** | **postulat** | l'aveu. Toute prémisse est un point de départ ; le **postulat dit de lui-même qu'il n'est pas démontré**. C'est un sous-ensemble, pas un synonyme — et la seule collision de gloses trouvée sur les 115 mots du domaine |
