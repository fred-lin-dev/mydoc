# 🎭 Nommer une attitude — quinze mots

> **Fiche de vocabulaire — faite pour être mémorisée.** Deux cartes par mot, dont une
> dans le sens *définition → mot*. Critère d'entrée dans [[MOC-Langues]].

**Famille : la disposition de quelqu'un, pas son acte.** C'est le vocabulaire qui
permet de décrire un comportement sans le juger moralement — ce que
[[Source-The_Presentation_of_Self_in_Everyday_Life]] fait sur cent pages et que ces mots
font en un.

---

## Les quinze

**velléitaire** :: qui forme des intentions sans jamais engager le premier geste. *Ex : il est velléitaire — six projets annoncés, aucun commencé.*
<!--ID: 1791036058209-->


**atermoyer** :: différer une décision en gagnant du temps, sans la refuser. *Ex : il atermoie depuis trois réunions.*
<!--ID: 1791036058212-->


**tergiverser** :: user de détours pour éviter de répondre ou de trancher. *Ex : arrête de tergiverser et dis oui ou non.*
<!--ID: 1791036058216-->


**dilatoire** :: dont la seule fonction est de retarder. *Ex : une question dilatoire posée pour épuiser le temps.*
<!--ID: 1791036058219-->


**péremptoire** :: qui tranche d'un ton n'admettant pas la contradiction. *Ex : un « c'est comme ça » péremptoire ferme la discussion.*
<!--ID: 1791036058222-->


**condescendant** :: qui marque sa supériorité en feignant de s'abaisser vers l'autre. *Ex : expliquer lentement à quelqu'un qui sait, c'est condescendant.*
<!--ID: 1791036058225-->


**obséquieux** :: dont l'empressement poli est excessif au point de paraître servile. *Ex : un accueil obséquieux met mal à l'aise.*
<!--ID: 1791036058231-->


**désinvolte** :: qui traite une chose avec une légèreté que la situation ne permet pas. *Ex : désinvolte sur un délai qui engageait toute l'équipe.*
<!--ID: 1791036058234-->


**pusillanime** :: qui manque de courage au moment de décider. *Ex : un arbitrage pusillanime, repoussé pour ne froisser personne.*
<!--ID: 1791036058238-->


**opiniâtre** :: qui tient bon sans se laisser détourner. *Ex : une opposition opiniâtre, jamais bruyante et jamais levée.*
<!--ID: 1791036058241-->


**circonspect** :: qui agit avec prudence, après avoir considéré les suites. *Ex : reste circonspect avant de t'engager par écrit.*
<!--ID: 1791036058244-->


**intransigeant** :: qui ne concède rien sur ce qu'il tient pour essentiel. *Ex : intransigeant sur la méthode, souple sur le calendrier.*
<!--ID: 1791036058247-->


**complaisant** :: qui cède pour plaire, au détriment de ce qui serait juste. *Ex : un retour complaisant n'apprend rien à celui qui le reçoit.*
<!--ID: 1791036058252-->


**affabuler** :: inventer un récit et le présenter comme vécu. *Ex : il n'exagère pas, il affabule.*
<!--ID: 1791036058256-->


**se targuer de** :: se vanter d'une chose comme d'un titre qui donnerait un droit. *Ex : il se targue d'une expérience que personne n'a vérifiée.*
<!--ID: 1791036058259-->

## Les quatre paires qui font le travail

| | | Ce que l'écart dit |
|---|---|---|
| **atermoyer** | **tergiverser** | l'objet du délai. On **atermoie sur une décision** — on la repousse ; on **tergiverse devant une question** — on esquive la réponse |
| **tergiverser** | **dilatoire** | qui porte le défaut. *Tergiverser* qualifie **la personne** ; *dilatoire* qualifie **le moyen**, et suppose une intention établie |
| **velléitaire** | **pusillanime** | où le courage manque. Le velléitaire **n'engage pas l'action** ; le pusillanime **ne prend pas la décision**. On peut être l'un sans l'autre |
| **complaisant** | **obséquieux** | ce qui est cédé. Le complaisant cède **sur le fond** pour plaire ; l'obséquieux n'en fait trop que **sur la forme** |

> **Pourquoi `intransigeant` et `opiniâtre` sont ici alors qu'ils sont élogieux.** Une
> famille d'attitudes qui ne contiendrait que des défauts serait un vocabulaire de
> reproche, pas de description. Et [[Concept-Minorité_Intransigeante]] montre que
> l'intransigeance est **un mécanisme**, pas un travers : la minorité qui ne cède
> jamais impose sa contrainte à la majorité qui, elle, s'accommode.
